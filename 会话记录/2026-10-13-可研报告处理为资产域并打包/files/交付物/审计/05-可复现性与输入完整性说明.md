## 2. 输入完整性事件（必须如实披露）

本次任务进行期间，工作区内由前序处理产生的中间文件 `input/大数据研究中心可研.md` 被**另一进程**追写了一份「附录A（处理者补充）外部规范与法定大纲核查」（追加后文件由 170,760 字节 / 2,632 行 变为 177,754 字节 / 2,679 行）。该附录**不是原报告内容**。

处置方式（不做无根据的猜测，只保证交付可复现）：

1. **不再依赖被改动的中间文件**：改为用纯标准库从原始 docx 的 `word/document.xml` 重新推导段落、标题（取 `w:pStyle` 1/2/3）与表格，得到干净文档文本；关键数字逐项复核一致（18319×28、13032×8、11188×3、2758×6、18219×1、18040×3、建标191-2018×3、952KW×1）。
2. **章节结构取自 docx 样式而非正则**：kp 的 `_parse_heading` 会把「1.财经特色鲜明…」这类**编号列表项**误判为标题，实测多出 20+ 个假章节；本包改用 docx 标题样式作为权威结构。
3. **chunk id 重映射**：抽取产物引用的旧 chunk id 与新推导的 chunk 不重合，按确定性规则（完全相同 → 一方包含另一方 → 字符二元组 Jaccard≥0.60）重映射，共映射 1145/1153；**抽取引用的 216 处锚点全部命中、0 处悬空**。
4. **那份附录被单独归位**：移入 `外部核查/`，标注为「非原报告内容 · 检索来源 · 拟采信前须核对」，**未并入 source/normalized.md，也未作为事实进入图谱**（见下节）。

> 该事件本身也印证了本包的铁律：**中间产物不作权威，原稿才是权威；任何非原稿内容必须显式标注、隔离、不混入。**

## 4. 工具层缺陷与绕行（均已留痕，未改动上游工程）

全部缺陷也以机读形式登记在 `SHUFE-BDC-2019-001/quality/tool_defects.yaml`。

| # | 严重度 | 位置 | 现象 | 本包绕行方式 |

| TD-1 | high | `corpus_pipeline/__init__.py :: stage_7_desensitize` | 脱敏替换对已插入的占位符二次替换，产生嵌套错乱骨架，并因 set 迭代顺序受 PYTHONHASHSEED 影响而不确定。 | 改为一次性 re.sub 左到右扫描（本脚本），产出文本不再被重新扫描。 |

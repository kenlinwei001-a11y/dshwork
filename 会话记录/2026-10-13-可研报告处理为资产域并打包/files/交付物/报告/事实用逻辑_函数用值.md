# 事实用「逻辑」、函数用「值」——规则固化与核验

> 用户给的规则（本文件据此固化）：
> **作为事实输入信息，用历史资产的「逻辑」而不是「值」；但对应函数等等，就需要用它的值。**

这条规则**修正了我上一轮的判断**——我把「函数类的值」也当成了泄漏嫌疑。

---

## 一、规则的分界线：不是「数字 vs 非数字」，而是「事实 vs 函数」

| 类别 | 含义 | 例 | 跨项目处置 |
|------|------|-----|-----------|
| **事实类** | 属于**某个具体项目**的取值 | 总建筑面积 18319 ㎡、总投资 13032 万元、各中心规划人数 120/180/300、地上需求 18040 ㎡ | **不继承** → 必须槽位化（`{面积}`、`{人数}`） |
| **函数类** | 属于**方法/规范/公式本身**的常数 | 人均建筑面积指标 16 ㎡/人、基本预备费费率 5%、未预见系数 10%、综合平面利用系数 0.55、活荷载标准值 2.0/4.0 kN/m²、单位换算 1000/10000 | **必须继承** → 剥离即资产不可用 |

**关键**：函数类的值**也是值**。上一轮我把 `0.55`、`0.20MPa` 当成泄漏报出来，方向是反的——
它们正是「函数需要的值」，清掉之后规则就无法执行。

---

## 二、按此规则重新核验：**两个方向的缺陷同时存在**

| 方向 | 类别 | 应有行为 | 实测 | 判定 |
|------|------|----------|------|------|
| **A. 清得不干净** | 事实类 | 槽位化 | 94 条中**残留 70 条** | ❌ 真泄漏 |
| **B. 清过了头** | 函数类 | 保留 | 44 条中**丢失 18 条** | ❌ 资产不可用 |

### A. 事实类残留（真泄漏，70 条）

| 残留值 | 属主 |
|--------|------|
| 18319 ㎡ / 18000 ㎡ / 319 ㎡ | 本项目·总/地上/地下建筑面积 |
| 13032 万元 | 本项目·总投资 |
| 65 / 300 / 60 / 360 / 120 / 400 … | 各研究中心规划科研人员与研究生人数 |
| 18040 ㎡ | 本项目·地上总建筑面积需求 |

这些出现在 `reuse/domains/07-rule.yaml` 的「规模链」描述里（形描述带值）：

```
规模链：表5-1~5-4 逐中心人数 → 合计 315/1350 → 人均指标法 → 地上需求 18040 ㎡ → 与设计 18000 ㎡ 比对
```

应改为：

```
规模链：逐中心人数 → 合计 {科研人数}/{研究生人数} → 人均指标法 → 地上需求 {面积} → 与设计 {面积} 比对
（人均指标法本身：人均建筑面积指标 = 16 ㎡/人【科研】、8 ㎡/人【研究生】—— 函数类，保留）
```

### B. 函数类丢失（18 条，**这是更要命的**）

| 丢失的函数常数 | 用途 | 丢失后的后果 |
|----------------|------|--------------|
| 综合平面利用系数 **0.55** | 使用面积 → 建筑面积换算 | 配套用房规模链断裂 |
| 楼面活荷载标准值 **2.5 / 3.5 / 10.0 kN/m²** | 科研用房/走廊门厅楼梯/变配电间水泵房 | 结构取值链无法复核 |
| 2020年目标·教师规模 950 人 | 规划目标口径 | 规模论证的目标值缺失 |

**为什么这更要命**：事实类残留只是「不该带的带了」，下游可以忽略；
而函数类丢失是「该有的没了」——下游**无法重新算**，只能回头问原作者，资产等于不可用。

---

## 三、根因：脱敏与域合成都做的是**无差别处理**

| 环节 | 实现 | 缺陷 |
|------|------|------|
| `stage_7_desensitize` / `s7b` | 把**所有**数值替换为 `{{node:…}}` | 未区分类别；且**未建模的数值无替换目标**，以字面留存（4,150 处） |
| `domain_source.py` 域合成 | 「借形不借值」按**全值剥离**执行 | 函数常数一并被剥离 → 资产不可用 |

**修法**：脱敏与合成都要**按类别分派**（分类判据见下）。

---

## 四、固化为客观判据 K13「事实用逻辑、函数用值」

```python
# 事实类谓词（该项目专属取值）→ 资产中必须为槽位，不得出现字面值
FACT_PRED = r"^总建筑面积|^地上建筑面积|^地下建筑面积|规划人数|规划科研人员|规划研究生|"
            r"估算金额|^总投资|建筑面积需求|^层数|用水人数|人数合计|在校生|专职教师|资产总额|收入"

# 函数类谓词（方法/规范/公式常数）→ 资产中**必须保留**该值
FUNC_PRED = r"系数|费率|指标|定额|标准值|限值|单价|折标|利用率|预备费|未预见|装配率|"
            r"间距|高度控制|换气次数|允许|不小于|不大于|密度|目标"
```

| 方向 | 判据 | 阈值 | verdict |
|------|------|------|---------|
| **A** | `事实类节点的字面值 ∩ 资产文件 = ∅` | 残留 = 0 | FAIL（泄漏） |
| **B** | `函数类节点的值 ⊆ 资产文件` | 丢失 = 0 | FAIL（过度脱敏） |

**注意 B 的反直觉之处**：常规的质量门禁都在查「有没有多余的东西」；
B 在查「有没有**少了该有的东西**」——它属于**闭环校验**（源侧应有的 ⊆ 产物），与 C1–C7 同一机制。

## 五、一句话

| 问题 | 答案 |
|------|------|
| 事实输入用逻辑还是值？ | **用逻辑**：事实类取值不继承，一律槽位化 |
| 函数呢？ | **用值**：函数类常数（指标/费率/系数/标准值/换算常数）**必须继承**，剥离即资产不可用 |
| 我上一轮错在哪？ | 把 `0.55`、`0.20MPa` 这类**函数常数**误报为泄漏——方向反了 |
| 实测两个方向 | 事实类**残留 70 条**（清了没干净）；函数类**丢失 18 条**（清过了头） |
| 哪个更严重？ | **B 更严重**：残留可以忽略，丢失会让下游无法重算，资产等于不可用 |
| 根因 | 脱敏与域合成都在做**无差别全值处理**，未按「事实/函数」分派 |
| 怎么固化 | 判据 **K13**：A 查残留（集合差）、B 查丢失（闭环） |

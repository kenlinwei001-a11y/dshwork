# 依据的「政策生效时间」标注——台账与判据

> 用户要求：**类似标准、规范，如果原文中有时间，则需要标注「政策生效时间」，因为这些是有时间效应的。**

---

## 一、现状审计：这一步确实缺

| 检查项 | 实测 |
|--------|------|
| 原稿引用标准时是否写生效时间 | **0 处**。报告全部只写名称（部分写编号），从不写版本生效日 |
| 外部依据原文里是否有时效信息 | **11 处**「自…起施行／实施日期／施行日期」——信息其实取到了，只是没抽成字段 |
| 语料包现有字段 | `mandates` 有 `effect_level`（效力层级）但**无生效日期**；`status`/`trace_status` 是检索状态，非时效 |
| 带「生效时间」字段的证据 | **0 / 524** |

**为什么必须补**：标准/规范/政策是有**时间效应**的——
引用是否成立，取决于「引用时点」是否落在「该版本生效窗口」内。
不标生效时间，就无法回答三个关键问题：这份依据**当时生效吗**、**现在还有效吗**、**有没有更新的版本取代它**。

## 三、这一步直接翻出两条新问题（此前 15 条待审里没有）

### 发现一：绿色建筑评价标准——**与编制时点同月切换**（最危险的一类）

| 事实 | 值 |
|------|----|
| 报告引用版本 | **GB-T50378-2014**（原稿原文） |
| 新版生效时间 | **2019-08-01**（GB/T 50378-2019 自该日起实施，旧版同时被替代） |
| 报告编制时点 | **2019 年 8 月** |
| 判定 | ⚠️ **同月切换**：报告在编制当月引用了刚被替代的旧版 |

**同类报告漏检率最高的一种**：跨月的版本切换容易被「我查了最新版」掩盖，
而**同月切换**（新版生效日与编制月相同）最容易被漏——因为两者的「年份+月份」看起来是一样的。

**影响面**：报告按该项目申报了「绿色建筑二星」，而二星评价的技术口径随版本变化——
引用版本错误会连带影响二星增量费用（已列在投资估算里）的合理性判断。

### 发现二：建筑给水排水设计标准——**超前引用**

| 事实 | 值 |
|------|----|
| 新版生效时间 | **2020-03-01**（GB 50015-2019） |
| 报告编制时点 | 2019 年 8 月 |
| 判定 | ⚠️ **编制时点尚未生效**：若报告已引用该**名称**（2019 版才启用的名称），属超前引用 |

**注意**：这与「引用已废止规范」是**相反方向**的错误——
一个引旧了、一个引新了；两者都属时效问题，但**判据不同**，因此必须分开判。

## 四、字段规范（补进依据条目）

每条依据类证据/条款新增 5 个字段：

| 字段 | 含义 | 必填条件 |
|------|------|----------|
| `effective_date` | 政策生效时间（施行/实施日期） | 原文或依据全文含该信息时**必填** |
| `effective_clause` | 生效表述的**原文片段**（可追溯） | 与 `effective_date` 同时 |
| `supersedes` | 被它替代/废止的旧文件 | 原文有「原…同时废止」时必填 |
| `superseded_by` | 替代它的新文件 | 已知时填 |
| `time_window` | 生效窗口 `[effective_date, superseded_date)` | 可计算时填 |

**判定字段** `timeliness_verdict` ∈ {`生效期内`, `未生效·超前引用`, `已废止`, `同月切换`, `待核`}。

## 五、固化为客观判据 K14「时效标注」

| # | 判据 | 算法 | 阈值 | verdict |
|---|------|------|------|---------|
| K14-a | **生效时间必填** | 若依据全文含「施行/实施日期」表述，则该依据条目必须有 `effective_date` | 缺失 = 0 | FAIL |
| K14-b | **引用窗口合法** | `编制时点 ∈ [effective_date, superseded_date)` | 越窗 = 0 | FAIL |
| K14-c | **同月切换单列** | `effective_date[:7] == 编制时点[:7]` | 命中须显式登记 | 待审（**不是 FAIL，但必须出现在冲突清单**） |
| K14-d | **反向核查（未生效）** | `编制时点 < effective_date` 却已引用 | 命中 = 0 | FAIL |

**K14-c 为什么要单列而不是直接 FAIL**：同月切换时，报告可能确实按新版编制（编制于月末、新版月初生效）。
机器无法判定，只能**标记待审**——这与全篇「冲突不裁决」的纪律一致。

## 六、抽取精度：一处必须说清的局限

台账第 1 行把「固定资产投资项目节能评估和审查**暂行办法**」识别成 2017-01-01 生效的对象，
而实际情况相反——**它才是被替代的旧办法**（新办法 2017-01-01 起施行，它同时废止）。

**原因**：抽取用「日期前后 ±260 字符窗口内找带『标准/规范/规定/办法』的书名号」来配对名称，
而生效句里往往同时提到新旧两个文件名（"《新》自…施行，《旧》同时废止"），窗口内会张冠李戴。

**改进方向**（不引入 LLM）：要求**名称与日期同句**（以 `。；` 为句界），
并在句内区分「自…施行」的主语与「同时废止」的宾语。本项列为抽取改进待办。

## 七、一句话

| 问题 | 答案 |
|------|------|
| 原文有时间就要标生效时间吗？ | **是**。标准/规范/政策有**时间效应**，不标生效时间无法回答「当时生效吗／现在还有效吗／有没有取代它」 |
| 现在做到了吗？ | **没有**：原稿 0 处标注、语料包 0/524 条证据有该字段；但外部依据原文里有 11 处信息可取 |
| 补上之后有什么收获？ | **翻出 2 条新问题**：绿色建筑评价标准**同月切换**（GB-T50378-2014 vs 2019-08-01）、建筑给水排水设计标准**超前引用**（2020-03-01） |
| 判据怎么定？ | **K14**：a 必填、b 窗口合法、c 同月切换单列待审、d 反向核查未生效 |
| 局限 | 名称与日期配对靠上下文窗口会张冠李戴（已实测到 1 处），须改为**同句配对** |

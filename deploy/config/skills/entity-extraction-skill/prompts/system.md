# Entity Extraction Skill

你是 NexusOne / 智演的 Entity Extraction Skill。严格遵守 SKILL.md 的输入、输出、来源绑定和不编造规则。

## 两类必须抽的实体

### 一、数值实体（主体+数值+单位三者可核验）

```
总建筑面积 = 18319 ㎡        → 实体「总建筑面积」
就业率 = 95 %                → 实体「毕业生就业率」
水泵 H = 75 m                → 实体「XX 型号泵」·参数「扬程」
```

**必须排除的无效数字**（建节点前逐条过）：

| 类型 | 例子 | 怎么判 |
|---|---|---|
| 章节号 | `6.4.2` `§5.6` | 上下文含「第N章/节/条款/见表/附录」 |
| 条款号 | `5.1.1` | 形态 `\d+\.\d+\.\d+` 且无单位 |
| 年份/日期 | `2019年` `2020年7月` | 时间点，不是可计算数值 |
| 序号 | `1.` `（3）` | 无单位 + 1~2 位整数 |
| 标准编号 | `GB50016-2014` | 前缀 GB/JGJ/DGJ/建标 |
| 文号 | `〔2019〕5号` | 前缀 〔 |

**时间点 vs 时长**（最容易错）：

```
「2020 年开工」      → 排除（时间点）
「工期 24 个月」      → 保留（可算进度）
「使用年限 50 年」    → 保留（可判合规）
判据：unit ∈ {年,月,日} 且上下文含「工期|使用年限|寿命|工作天数」→ 保留
```

**规范要求 ≠ 项目取值**：

```
「无障碍电梯候梯厅深度 >1.8m」  → 这是 GB50763 的要求，不是本项目设计值
                              → 归 E2 证据，不建 fact
```

### 二、判断句里的实体

句中有判断词时，抽三类实体：

```
① 判断主体：谁做判断（编制方 / 评审方 / 标准）
② 判断对象：判断什么（建设必要性 / 规模合理性 / 资金保障）
③ 判断依据：凭什么（政策文件 / 数据 / 规范）—— 常为空，空即记缺口
```

**判断词四族，决定抽什么**：

| 族 | 词 | 要抽的实体 |
|---|---|---|
| 结论 | 充分/合理/必要/可行/良好/有利/显著/可控 | 判断对象 |
| 建议 | 建议/宜采用/推荐 | 建议对象 + 建议动作 |
| 预测 | 可能/预计/力争/届时/将达 | 预测指标 + 目标值 + 时点 |
| 推理 | 由于/导致/从而/因此 | 前提 + 结论 |

**每条判断必须带 `falsifiable_by`**：说不清什么能推翻它的，不是判断，是口号，不抽。

### 三、三项检查（抽完必做）

| 检查 | 判据 | 不通过 |
|---|---|---|
| 数值可算性 | 有值实体的主体/单位是否齐全 | 记缺口，不建孤值节点 |
| 判断有据性 | `evidence_refs` 是否非空 | 标「报告缺证据」，不改原文 |
| 无效数字拦截 | 排除规则是否命中 | 命中即不建 |

### 铁律

> 数值实体不是「有数字就算」，而是「主体+数值+单位三者可核验才算」。
> 章节号、条款号、年份、序号都是数字，但都不是实体。

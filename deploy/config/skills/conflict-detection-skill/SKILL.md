# Conflict Detection Skill

## Skill ID
SK-13

## Purpose
检测数字、时间、实体、Claim 和版本之间的冲突，并输出待审状态而非自动裁决。

## 何时使用

- 调用条件：上游产物与 project_id / document_id / version_id 齐备
- 典型请求：前后数字对不上｜不同版本之间有矛盾｜列出所有待审冲突
- 不要在此调用：拍板选一个值（交人工或评审）
## 边界与不适用

- 不做：绝不自动裁决或静默选值
- 不做：每条冲突给出双方出处与差异点
- 缺输入：先有可比数据（同指标多来源或多版本）

## 一、核心指标标准

### 《普通高等学校建筑面积指标》建标191-2018

本垂类全部规模测算的依据。

**⚠️ 使用前必须核验三件事**（`norms.yaml` 已给检索式）：

1. 是否现行有效、有无替代版本
2. **适用范围是否覆盖「专职科研机构用房」**——这是本垂类最关键的边界问题，属边界情形，必须查清而不是默认
3. 正式名称到底含不含「规划」二字（真实报告里被引错过）

**实务中观察到的分档方式**（非规范原文，取值须逐项目与现行版本核对，**不得直接套用**）：

| 用房类型 | 常见分档 |
|---|---|
| 科研人员用房 | 一档，人均指标较高 |
| 研究生 / 博士生 / 访问学者用房 | 另一档，人均指标较低 |

**计算式**（形状固定，取值逐项目确认）：

```
科研用房需求 = 科研人员数 × 科研人员指标 + 研究生等人数 × 研究生指标
配套用房需求 = 配套使用面积 ÷ 使用面积系数
总需求      = 两者之和
```

合成样例：240 × 16 + 900 × 8 = 3840 + 7200 = 11040 ㎡。

**「访问学者」归哪一档要问清楚。** 常见做法是与研究生并为一档，但这是编制单位的处理，不是规范明文。

### 公共服务配套用房的换算系数

常见取值 **0.55**（合成样例：使用面积 900 ㎡ ÷ 0.55 ≈ 1800 ㎡ 建筑面积）。

**这个系数没有国标依据**，是编制单位口径，各项目取值不同。必须标为 E1（客户给定）并请客户确认，不得当成 E2（规范）引用——否则 C5 会因找不到依据而报缺 backing。

典型配套清单：交流讨论室、接待室、报告厅、活动室、阅览室、档案室、复印室、贮藏室。这些给的都是**使用面积**，必须换算后才能与科研用房相加。

## 二、上位政策与管理办法

| 文件 | 角色 | 用途 |
|---|---|---|
| 发改投资规〔2023〕304号 | benchmark + 编制依据 | **法定基准**，章节覆盖依此 |
| 《教育部直属高校基本建设管理办法》 | benchmark | 部属高校的建设程序与审批口径 |
| 学校"十四五/十五五"事业发展规划、基本建设规划、校园总体规划 | driver + benchmark | 内部驱动 + 合规基准 |
| 学校推进"双一流"建设方案、学科建设规划 | driver | **D1 必要性的核心论据** |
| 校党委常委会/校长办公会关于本项目的决议 | E6 行政批复 | 内部立项依据，须带文号 |

**注意角色区分**：校园总体规划在必要性章是 `driver`（规划要求建这个），在合规性小节是 `benchmark`（本项目符合规划）。同一份 Mandate 节点，两条不同的边，服务两个不同维度。塌缩它们是可研里常见的论证含混。

## 三、科研用房区别于普通办公的设计要点

这些是评审专家会追问的地方，写通用条款会被指出：

**实验室专项**

- 通风：换气次数按实验类型分区取值，通风柜数量与排风量
- 排污：实验废水分类收集与预处理，不得直排市政
- 供电：实验设备负荷等级、UPS 与应急电源、防浪涌
- 防振：精密仪器区的振动限值与结构措施
- 恒温恒湿：温湿度控制精度与相应的空调形式
- 危化品：储存间的防爆、泄爆、气体检测报警
- 洁净：若含洁净室，等级与压差控制

**消防**

实验室火灾荷载与常规办公不同，防火分区、疏散距离、灭火系统形式要单独论证。

**跨专业耦合的枢纽参数**——改这几个会牵动多专业，务必先确认（G2 闸门）：

```
建筑分类等级 ──┬→ 耐火等级 → 消防系统配置
              ├→ 抗震设防烈度 → 结构形式与荷载取值
              ├→ 负荷等级 → 供配电方案
              └→ 防烟排烟标准 → 暖通方案

总建筑面积 ──┬→ 用水定额 → 最高日用水量 → 管径 → 消防水池容积
            ├→ 用电指标 → 计算负荷 → 变压器容量
            └→ 冷热负荷指标 → 冷热负荷 → 机房面积 → 反馈修正总面积
```

最后一条是**回环**（面积→机房→面积）。检查器会报 `CYCLE` 并给出环路径，需人工设切断点与收敛条件，不要静默忽略。

## 四、拆除重建类项目的额外要求

科研用房项目常伴随既有建筑拆除（拆除既有教学楼原址重建是典型情形）。拆除会带来四件事，**缺一评审都会问**：

1. **拆除面积与拆除费**——面积须与产权/测绘资料一致
2. **CH5.4 用地用海征收补偿（安置）方案不可豁免**——常见误解是"校内自拆不算征收"，但既有建筑的腾空、原使用单位的安置、施工期过渡用房都要交代
3. **拆除手续办理进度**——常见写法是"拆除手续正同步办理中"，这属于前置条件未闭合，应在 CH9 风险中说明
4. **CH9 社会稳定风险**——师生对施工噪音、通行、过渡安置的关切

## 五、造价参考

**本 skill 不对造价数值负责**，单价由造价咨询单位提供，**任何量级参考都不得直接套用**。

单方造价的可比性由以下条件共同决定，比较时必须逐项对齐，缺一条比较就不成立：

| 可比性条件 | 说明 |
|---|---|
| 地域与价格年份 | 人工与材料价差异极大，跨年跨省须调价 |
| 装配率 | 装配式比例越高单方越高 |
| 绿建星级 | 星级越高附加措施费越多 |
| 装修标准 | 毛坯 / 简装 / 精装差一个量级 |
| 有无地下室 | 地下室显著抬高单方 |
| 实验室专项是否计入 | 通风、排污、防振、恒温恒湿会大幅推高 |

**科研用房的单方造价通常高于普通办公**——实验室的通风、排污、供电、防振要求会显著推高。做横向比较时要剔除这部分差异，并按 E5 类比证据的要求说明可比性条件。

**费用构成**：

```
总投资 = 建筑安装工程费 + 工程建设其他费 + 基本预备费 + 拆除费
基本预备费 = (建安费 + 其他费) × 5%
```

工程建设其他费通常含：建设单位管理费、前期咨询费、勘察费、设计费、招标代理费、监理费、审图费、竣工图编制费、场地准备及临时设施费、市政配套费、人防易地建设费。

常见**不含项**（须在估算说明中显式声明）：办公家具与电器、**实验室专用仪器设备**、大市政增容费（校区内统筹）、地下障碍物清除费。

> 实验室仪器设备费是否计入总投资，各校口径不同，**必须在分诊时问清楚**——它金额巨大，漏问会导致投资估算整体失真。

## 六、编制时的自查清单

1. 规划人数是否分类给出（科研人员 / 研究生 / 博士生 / 访问学者）
2. 面积指标是否绑定建标191-2018 现行版本，适用范围是否覆盖专职科研机构
3. 配套用房的使用面积系数是否显式声明并标为客户口径
4. 设计面积超需求时是否说明了超出部分的构成
5. 拆除的四件事是否齐全（面积费用 / 征收补偿方案 / 手续进度 / 稳评）
6. 实验室专项设计是否写实，还是套了通用条款
7. 实验室仪器设备费是否计入，口径是否说明
8. 是否有项目产出方案（新增多少科研工位、支撑哪些学科方向）
9. 是否有数字化方案（2023 新增必备，常缺）
10. 是否有运营方案整章，绩效指标是否是科研口径（使用率/共享机时/产出）而非通用指标
11. 是否有碳达峰碳中和分析（2023 新增必备）
12. 是否有风险应急预案（CH9.3，常缺）
13. 必要性论证有没有断链——从政策直接跳到"必须建"，中间的推理许可要写出来

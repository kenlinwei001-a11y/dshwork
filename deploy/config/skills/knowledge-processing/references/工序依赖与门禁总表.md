## 工序依赖与门禁总表

```
S1 归一化 ──┬─→ S1b 表格解析 ──┐
            └─→ S2 骨架 ──→ S3 切块 ──┴─→ S4 本体抽取
                                              ↓
                                        S5 推演回放
                                              ↓
                                        S6 质量登记
                                              ↓
                                        S7 脱敏索引
```

| 门禁 | 不通过的后果 |
|---|---|
| S1 归一化 | 回不到原文，溯源链断 |
| **S1b 表格** | **列名丢失，subject 退化** |
| S2 大纲 | 法定章节漏写 |
| S3 切块 | 切块丢失内容 |
| S4 抽取 | 论断/证据分类错，写作口径错 |
| S5 派生 | 规则静默跳过，数值无来源 |
| S6 质量 | 假缺泛滥，公信力崩塌 |
| S7 脱敏 | 跨项目复用失效 |

**任何一项 covered < total → 装配侧拒绝发布。**

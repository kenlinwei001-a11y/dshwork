# 一致性检查清单

| 类型 | 检查 | 典型冲突 |
|---|---|---|
| 数值 | 报告结果 vs 原始记录 vs 复算值 | 报告 3.36，记录 3.63 |
| 日期 | 采样 ≤ 接收 ≤ 检测 ≤ 报告；校准有效期覆盖检测日期 | 校准证书过期 |
| 方法 | 报告声明 vs 原始记录 vs 库内标准 | 报告 GB 11893，库内 HJ 671 |
| 仪器 | 报告附表 vs 运行记录 vs 校准证书 | N-187 vs N-188 |
| 样品 | 数量/编号/状态 | 报告 15 个，流转 14 个 |
| 单位 | mg/L、μg/L、%、℃ | 检出限 0.05 mg/L，结果 μg/L |
| 签字/章 | 报告声明与规则 | 缺批准人签字/检测章 |

## 方法 mismatch 处理

- 单列 finding，type=method_mismatch，severity=high；
- 该标准不参与合格判定；
- 建议：补 GB 11893 规则集或改用 HJ 671 重测后再审。

## 假通过信号

- PASS 但 target=UNLOCATED；
- observed 是推断值，无 quote；
- 用错方法规则；
- ND 被当 0 参与计算；
- 同一条款另一处证据冲突；
- 缺证但 on_missing 被忽略。

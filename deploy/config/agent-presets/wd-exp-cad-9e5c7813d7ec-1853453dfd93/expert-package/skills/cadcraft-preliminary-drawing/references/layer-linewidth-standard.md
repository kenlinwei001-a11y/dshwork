# 图层、线宽、字体与标注样式

本表按常规建筑工程制图习惯整理，可作为默认值；院标或甲方标准更严时从其规定，并在图纸说明中注明采用的图层体系。

## 2. 线宽层级

| 层级 | 线宽 (mm) | 用于 |
|---|---|---|
| 特粗 | 0.70 | 图框外框、剖切位置线、总平用地红线（按院标） |
| 粗 | 0.50 | 墙体、柱、剖切到的构件轮廓 |
| 中 | 0.35 | 楼梯、阳台、台阶等次主要构件、防火分区线 |
| 中细 | 0.25 | 门窗、索引符号、引出线、可见轮廓 |
| 细 | 0.18 | 尺寸线、文字、轴号、图例 |
| 最细 | 0.13 | 填充线、辅助线、网格 |

打印使用单色样式：按颜色映射线宽，不用"打印对象线宽"以外的临时设置，保证换机器出图一致。

## 3. 字体与字高

| 项目 | 约定 |
|---|---|
| 中文字体 | 长仿宋、仿宋或宋体类工程字体；同一套图只用一种 |
| 西文字体 | 与中文同族或无衬线工程字体 |
| 宽高比 | 约 0.7（长仿宋） |
| 图面字高 (mm) | 常用 2.5、3.5、5、7、10、14、20 |
| 最小字高 | 打印后不小于 2.5 mm；不满足时提高字高或降低比例分母 |
| 图层内字高 | 房间名 3.5–5；面积 2.5；尺寸数字 2.5–3.5；图名 7–10；图号 5–7 |

### 模型字高换算（模型 1:1，单位 mm）

| 图面字高 | 1:50 | 1:100 | 1:150 | 1:200 |
|---|---|---|---|---|
| 2.5 | 125 | 250 | 375 | 500 |
| 3.5 | 175 | 350 | 525 | 700 |
| 5 | 250 | 500 | 750 | 1000 |
| 7 | 350 | 700 | 1050 | 1400 |
| 10 | 500 | 1000 | 1500 | 2000 |

## 4. 尺寸标注样式

| 参数 | 图面值 | 1:100 模型值 |
|---|---|---|
| 箭头（建筑斜线或实心箭头） | 2.5 mm | 250 |
| 尺寸界线起点偏移 | 2 mm | 200 |
| 尺寸界线超出尺寸线 | 2 mm | 200 |
| 文字距尺寸线 | 0.7 mm | 70 |
| 平行尺寸线间距 | 7–10 mm | 700–1000 |
| 文字高度 | 2.5–3.5 mm | 250–350 |
| 精度 | 0（整数 mm） | — |
| 角度精度 | 度分秒 | — |

规则：尺寸数字不标单位；同一张图内尺寸样式唯一；三道尺寸由外到内为总尺寸、轴线尺寸、墙段与洞口尺寸；不标注重复尺寸与封闭尺寸链。

## 5. 标高符号

- 三角形标高符号高约 3 mm（图面），横线长度按文字长度。
- 单位米，保留三位小数，带 ± 号；±0.000 的绝对标高写在总平面与设计说明中。
- 平面图注楼面建筑标高；剖面图注层高与净高；立面图注室外地坪、各层、檐口/女儿墙、总高。

## 6. 自检

- [ ] 图层齐全、无 0 层图元
- [ ] 线宽分组正确，打印预览层级可辨
- [ ] 字高换算正确，无小于 2.5 mm 的打印字高
- [ ] 标注样式比例与图框比例一致
- [ ] 填充不遮挡文字与尺寸
- [ ] 目视可辨：用 craftcad-ui 打开并截图，墙柱（粗）/门窗（中）/标注（细）三级线宽在屏幕上仍能区分

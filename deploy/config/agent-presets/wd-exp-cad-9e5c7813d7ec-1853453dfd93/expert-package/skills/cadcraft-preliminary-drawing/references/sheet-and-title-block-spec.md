# 图幅、图框、标题栏与出图规则

## 1. 图幅（横式，mm）

| 图幅 | 尺寸（宽×高） | 常用场景 |
|---|---|---|
| A0 | 1189×841 | 大型总平、综合平面 |
| A1 | 841×594 | 初设建筑平面、立面、剖面（推荐） |
| A2 | 594×420 | 中小型项目的平面、剖面 |
| A3 | 420×297 | 节点详图、说明、表格 |
| A4 | 297×210 | 目录、表格（一般不用作图形图幅） |

同一套图尽量统一图幅；混排时图纸目录中标明每张图幅。

## 2. 图框

- 装订边（左侧）25 mm，其余三边 10 mm；内框线宽 0.50 mm，外框 0.70 mm（按院标可调）。
- 图框内不得压字、压图；图名与图号放在图框内、图形下方居中或标题栏内。
- 图框建议做成块并固定插入点，整套图复用，避免每张手画。

## 3. 标题栏（右下角）

常用尺寸约 180×40 mm，按院标分格。必备字段：

| 字段 | 内容 |
|---|---|
| 工程名称 | 项目全称（与合同/报建名称一致） |
| 子项/单体 | 单体名称或编号 |
| 图名 | 如"首层平面图" |
| 图号 | 按图号规则编制 |
| 设计阶段 | **初步设计**（不得写"方案"或"施工图"） |
| 比例 | 如 1:100 |
| 设计/绘图 | 绘制人 |
| 校对 | 校对者 |
| 审核 | 审核者 |
| 专业负责人 | 建筑专业负责人 |
| 日期 | 出图日期（YYYY.MM.DD） |
| 版本 | V1.0、V1.1 … |

## 4. 会签栏

- 位于图框左上或左侧，按专业分格（建筑、结构、给排水、暖通、电气），每格含专业、姓名、日期。
- 初设阶段各专业会签按项目流程执行；未签的格留空，不代签。

## 5. 图纸目录

表格列：序号、图号、图名、图幅、比例、版本、张数、备注。

目录要求：
- 与图纸一一对应，图号连续，无缺号、无重号。
- 首页为图纸目录；成册 PDF 顺序与目录一致。
- 目录本身也占一张图（图号可为"初设-建-00"）。

## 6. 图号规则

推荐：阶段代号-专业代号-序号。

- 阶段代号：初设（初步设计）。
- 专业代号：总（总图）、建（建筑）、结（结构）、水（给排水）、暖（暖通）、电（电气）。
- 序号：两位数字，从 01 起；目录用 00。

示例：初设-建-00（目录）、初设-建-01（总平面）、初设-建-02（首层平面）、初设-建-05（立面）、初设-建-07（剖面）。

版本：V主版本.次版本；改图递增次版本，出图范围或深度变化递增主版本。

## 7. 修订记录

每次改图在图框外或目录后附修订记录：版本、日期、修订内容、修订人、审核人。修订内容写"改了什么 + 为什么"，不写"修改"。

## 8. PDF 出图要求

- 页面尺寸等于图幅，横向；不缩放、不裁切。
- 单张导出后按图号顺序合并；首页为图纸目录。
- 矢量输出，文字可搜索（不是图片化文字）；字体嵌入或转为可读矢量。
- 黑白打印线宽可辨：0.13 mm 以上的线在 100% 打印下应可见。
- 文件命名：项目简称-专业-阶段-图名-图号-版本-日期.pdf。
- 交付前逐页预览：无空白页、无缺图、无越界、无重叠文字。

## 9. 与 DXF 的关系

- DXF/DWG 是源文件，保留全部图层与可编辑性，随交付一并归档。
- PDF 是成品，供评审、报建、打印；两者内容必须一致。
- 图纸目录中的张数以 PDF 页数为准，DXF 文件数与图纸数也应一致。

# 初步设计建筑专业出图深度检查表

依据初步设计阶段的一般深度要求与常规院标整理。地方规定、行业专项（医疗、教育、人防、超高层）要求更严时从其规定。逐项打勾，未过项进"待确认清单"。

## 0. 图纸组成（建筑专业最小集）

1. 总平面图
2. 各层平面图（首层、标准层、地下层、屋面层）
3. 立面图（不少于两个，主要立面齐全）
4. 剖面图（不少于一个，复杂项目两个）
5. 主要节点详图（外墙、楼梯、卫生间、屋面、变形缝等）
6. 设计说明（工程概况、防火、无障碍、节能、材料做法）
7. 门窗表
8. 房间面积表与主要技术经济指标
9. 图纸目录

## 1. 总平面图

- [ ] 用地红线、建筑控制线、道路与出入口
- [ ] 建筑定位（坐标，或与红线/道路/既有建筑的关系尺寸）
- [ ] 建筑名称、层数、高度、±0.000 对应绝对标高
- [ ] 消防车道、消防登高面、与相邻建筑间距
- [ ] 绿地、停车、场地竖向（初设可示意）
- [ ] 指北针、比例、图例

## 2. 平面图

- [ ] 轴网、轴号、总尺寸、轴线尺寸、墙段与洞口尺寸（三道）
- [ ] 墙厚、柱截面、剪力墙（建筑表达）
- [ ] 门窗洞口、宽度与编号（与门窗表一一对应）
- [ ] 楼梯踏步数、上下方向、梯段宽；电梯井道与门洞
- [ ] 房间名称与面积（m²，两位小数，口径统一并注明）
- [ ] 楼面标高（建筑标高）
- [ ] 防火分区界线与面积、疏散楼梯与出口、疏散距离（按项目要求）
- [ ] 剖切符号、索引符号、详图编号
- [ ] 卫生间洁具、管井、设备位（初设示意）
- [ ] 无障碍设施（坡道、电梯、卫生间、扶手）

## 3. 立面图

- [ ] 立面朝向、轴号范围
- [ ] 层高、总高、檐口/女儿墙标高、室外地坪标高
- [ ] 外装材料与分格（初设可定性：幕墙/面砖/涂料/金属板）
- [ ] 门窗形式、开启方式、分格
- [ ] 雨水管、空调机位、百叶、栏杆等可见构件
- [ ] 与平面轮廓、屋面形式一致

## 4. 剖面图

- [ ] 剖切位置与轴号（与平面剖切符号一致）
- [ ] 层高、净高、楼板厚度示意、梁高示意
- [ ] 楼梯剖面（踏步高宽、梯段净高、平台宽）
- [ ] 屋面构造层次（初设层次）、地下室与覆土
- [ ] 室内外高差、排水方向

## 5. 主要节点详图

- [ ] 外墙构造：保温、防水、饰面、基层
- [ ] 楼梯：踏步防滑、栏杆高度与做法
- [ ] 卫生间：沉箱/降板、防水、地漏、门口高差
- [ ] 屋面：女儿墙、檐口、排水、变形缝
- [ ] 与平面、剖面尺寸一致

## 6. 设计说明与表

- [ ] 工程概况：地点、规模、层数、高度、耐火等级、抗震设防（按提资）
- [ ] 防火设计：分类、分区、疏散、构造
- [ ] 无障碍设计
- [ ] 节能与绿色建筑：主要指标与措施（初设定性 + 指标）
- [ ] 主要材料做法表
- [ ] 门窗表：编号、洞口尺寸、数量、材质、防火等级
- [ ] 房间面积表、各层面积、总建筑面积、容积率等（与总平、平面一致）

## 7. 制图与出图

- [ ] 图框、标题栏、会签栏齐全，设计阶段为"初步设计"
- [ ] 图号连续，图纸目录与实际图纸一致
- [ ] 比例标注与实际比例一致
- [ ] 图层规范，无 0 层杂物
- [ ] PDF：页数等于图纸数、首页目录、文字可搜索、黑白可读
- [ ] 目视校核（craftcad-ui：open → zoom extents → screenshot）：图框/标题栏完整、图名不截断、三级线宽可辨、文字无重叠、标注不越界、填充不盖字
- [ ] 截图与 DXF 摘要一致（实体数、图层数、范围），不一致以 DXF 为准

## 8. 交叉一致性矩阵

| 检查项 | 平面 | 立面 | 剖面 | 详图 | 表/说明 |
|---|---|---|---|---|---|
| 层数与层高 | ● | ● | ● | ○ | ● |
| 总高与标高 | ○ | ● | ● | ○ | ● |
| 轴网与轴线 | ● | ● | ● | ○ | ○ |
| 门窗编号 | ● | ● | ○ | ○ | ● |
| 房间名与面积 | ● | ○ | ○ | ○ | ● |
| 材料与做法 | ○ | ● | ● | ● | ● |
| 防火分区与疏散 | ● | ○ | ○ | ○ | ● |

● 必查　○ 相关时查。任一格出现不一致，先统一基准再改图，不在单张图上"就地修改"。

## 9. 交付判定

全部必查项通过 → 可按初设深度交付；存在未过项 → 出"待确认清单 + 整改清单"，明确哪些需甲方/专业负责人确认，哪些需补充资料。不得用"基本符合"替代结论。

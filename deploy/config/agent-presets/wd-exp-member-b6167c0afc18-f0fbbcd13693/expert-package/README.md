# 水常规元素检测报告质控专家团（water-routine-qc-team）

面向水常规元素检测报告（总氮、总磷、氨氮、无机阴离子等）的四人质控团队。

## 角色

- 主理人：柯守真（水常规元素检测报告质控总监）
- 沈证源：实验室证据抽取
- 顾合规：检测报告审核（C1/C6）
- 严留痕：过程文档审核（C2–C5/C7）
- 甄定论：审核裁定

标准要素抽取专家是**独立专家**，不在团内；标准规则必须先进入全局标准库。

## 工作流

1. 准备：项目、报告、标准关联、版本锁定；
2. 证据：报告 + 过程文档 → 证据包、span、缺件；
3. 并行审核：报告 C1/C6 + 过程 C2–C5/C7；
4. 裁定：合并、一致性、假通过复核、最终结论；
5. 交付：审核报告、页面、缺失清单、DB。

## 硬口径

- 标准抽取独立，缺规则停止；
- 缺证不默认通过；
- 方法 mismatch 不混入合格；
- 结论必须回指 rule_id、证据位置、条款；
- 成员独立输出，主理人不代写、不模拟。

# 样例审核：202203001 过程文档

## 1 文档清单

- D04 样品出入库登记表
- D06–D09 原始记录：总氮、总磷、氨氮、硝酸根/磷酸根
- D11 环境记录表
- D12 仪器运行记录-离子色谱
- D13 仪器运行记录-紫外可见分光光度计
- D14–D16 仪器校准证书-离子色谱（3 张）
- D01–D03、D05 委托/合同评审/任务单/风险评估

## 2 预期核查

1. 样品数量 15、编号 2022-03-15-1～2022-03-17-5、采样/接收日期与报告一致。
2. 原始记录四个项目各一本：校准曲线、空白、平行、加标、试剂、仪器参数、环境。
3. 仪器编号 N-187（UV）、N-210（IC）与报告附表一致；校准证书在检测日期内有效。
4. **缺件待核**：包内仅见离子色谱校准证书 3 张，未见 UV 校准证书；试剂配制记录是否含在原始记录内；质控样记录。
5. 方法 mismatch：总磷原始记录若按 GB 11893-89，则不能用 HJ 671 的 C2–C7 规则判；标 CONFLICT_PENDING。
6. 记录间冲突：原始记录结果与报告结果表若不一致，交 5 号裁定。

## 3 不做

- 不审报告结果表与公式复算（3 号）；
- 不直接判最终合格/不合格（5 号）；
- 不补造缺件。

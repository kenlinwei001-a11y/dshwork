# 水常规元素检测报告质控 playbook

## 适用

- 水常规元素检测报告（总氮、总磷、氨氮、无机阴离子等）；
- 一个委托批次的多份报告；
- 报告包含委托、任务单、样品流转、原始记录、环境、仪器、校准证书；
- 标准库已有对应方法规则。

## 角色

| 角色 | Agent ID | 职责 |
|---|---|---|
| 主理人 | water-routine-qc-team-lead | 准备、派工、检查、汇总 |
| 证据 | lab-evidence-extractor | 证据包、span、缺件 |
| 报告审核 | report-audit-expert | C1/C6 |
| 过程审核 | process-audit-expert | C2–C5/C7 |
| 裁定 | audit-adjudicator | 合并、一致性、假通过、结论 |

标准要素抽取专家是独立专家，不在团内；标准规则必须先入全局库。

## 四阶段

| 阶段 | 执行 | 输入 | 输出 | 检查 |
|---|---|---|---|---|
| P0 准备 | 主理人 | 项目 brief、报告包、标准库 | 项目/报告/标准关联、版本锁定 | 方法-标准匹配、报告包完整 |
| P1 证据 | 沈证源 | 报告包、方法清单 | 证据包、report_evidence、缺件 | 文档数、LOCATED、mismatch、缺件 |
| P2 报告审核 | 顾合规 | 证据包、C1/C6 规则 | 报告审核结果 | 规则覆盖、span、on_missing |
| P2 过程审核 | 严留痕 | 证据包、C2–C5/C7 规则 | 过程审核结果 | 记录覆盖、仪器/试剂/质控 |
| P3 裁定 | 甄定论 | P2 两份结果、证据、缺失 | 最终结论、问题清单、整改 | 一致性、假通过、mismatch |
| P4 交付 | 主理人 | P3 结果 | 报告/页面/DB/说明 | 可回指、缺件、限制 |

P2 的报告审核与过程审核可并行；其余串行。

## 硬口径

- 标准抽取独立，不在团内；缺规则停止。
- 缺证不默认通过；按 on_missing。
- 方法 mismatch 不参与合格判定，单列。
- 报告审核不审过程记录；过程审核不审报告结果。
- 所有跨成员信息经主理人中转。
- 成员独立输出，主理人不代写、不模拟。
- 结论必须回指 rule_id、证据位置、条款。

## 交付

- 审核报告 Markdown；
- 审核页（target span 高亮）；
- missing 清单；
- audit_run/audit_result；
- 版本/限制说明。

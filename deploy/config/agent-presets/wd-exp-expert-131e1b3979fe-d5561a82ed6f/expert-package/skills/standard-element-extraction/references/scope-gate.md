# 抽取准入闸（Scope Gate）—— 决定"抽什么 / 不抽什么"

> 本文件是标准要素抽取的**第一道闸**，先于条款解析、要素抽取、规则化。
> 目标：让 1000 个标准走同一套判定、产出同一套载体，而不是 1000 份风格各异的笔记。

## 0 唯一判据

一个内容该不该进**运行层**，只问一句：

> **它能不能支撑一次判定动作？**

不是问"它是规范性还是资料性"，也不是问"它重要不重要"。

## 1 八个判定原语（Audit Primitives）

任何可判定的要求，必能归约到下列之一；归约不了 → 不是规则。

| # | 原语 | 形态 | 例 |
|---|---|---|---|
| P1 | 阈值比较 | `field OP value [unit]` | 分离度 ≥1.5；r ≥0.995 |
| P2 | 集合归属 | `field ∈ set` / `∉ set` | 样品类型 ∈ {地表水,地下水,工业废水,生活污水} |
| P3 | 存在性 | `field/record exists` | 报告须载明方法检出限 |
| P4 | 条件-后件 | `if cond then require` | ρ<测定下限 ⇒ 须加限定符 |
| P5 | 时序/时限 | `t_B − t_A ≤ N` | 采样至分析 ≤14 天 |
| P6 | 计数/配额 | `count ≥ N per batch` | 每批空白 ≥2 个 |
| P7 | 映射/查表 | `lookup(key) → value` | 体系→峰序；离子→检出限 |
| P8 | 禁令 | `must_not field ∈ forbidden` | 其余离子不得加固定剂 |

## 2 六类载体（Artifact Types）

| 载体 | 用途 | 必填字段 | 进运行层 |
|---|---|---|---|
| **R 规则** | 判 PASS/FAIL | rule_id, primitives[], eval_ast, param_refs[], evidence[], on_missing, on_fail, anchor, fail_examples[] | ✅ |
| **P 参数** | 规则取值 | key(ion,param), value, unit, op, provenance{table,row,col,page} | ✅ |
| **M 映射表** | 查表判定 | mapping_id, key_domain, value_domain, rows[], provenance | ✅ |
| **G 护栏** | 防误用标准内容 | guard_id, forbidden_use, reason, anchor | ✅ |
| **B 边界** | 判不了时说什么 | boundary_id, kind(REF_PENDING/EXTERNAL/AMBIGUOUS/UNDEFINED), affected_rules[], request | ✅ |
| **A 档案** | 可复核不参与判定 | archive_id, content, retrieval_key, provenance | ❌ 按需检索 |

## 3 决策树（逐条款执行，多标签输出）

```
1. 背景判定
   informative 且 无"应/须/可/不得" 且 非表注/图注 且 非附录 → SKIP
2. 表格/图判定（先于内容判定，防资料性表格被一刀切跳过）
   含行列结构或峰序 → A（原始数据）
      被判定引用？ 是 → 再加 M（只抽被引的行/列）
3. 可判性判定
   可归约到 P1–P8 → R（阈值另补 P）
   不可归约 → 4
4. 引用转移判定
   指向外部文件 → B(REF_PENDING)；指向说明书 → B(EXTERNAL)；多种读法 → B(AMBIGUOUS)
5. 误用防护（全局一次）
   标准中"资料性/供参考/亦可"的数值 → G（禁止当阈值）
6. 剩余
   含可核事实 → A；纯叙述/原理/修订说明 → SKIP
```

## 4 三问自检（任一答不出，不得进运行层）

1. **判什么**：对哪个报告字段/记录下判断？
2. **对谁**：适用条件是否可机判（离子/基质/文档类型）？
3. **依据哪条**：clause + page + quote 是否齐全？

## 5 规模化度量（每标准自动算，不看内容也能发现抽偏）

| 指标 | 定义 | 健康区间 | 异常含义 |
|---|---|---|---|
| 判据密度 ρ | 规则数 / 规范性条款数 | 0.6 – 2.0 | <0.3 抽漏；>2.5 过度形式化 |
| 可判率 e | 可求值规则 / 全部规则 | ≥0.95 | 阈值不唯一、模糊表述未形式化 |
| 档案比 a | 档案项 / 全部载体 | 0.1 – 0.4 | >0.5 把档案当判据 |
| 边界率 b | 边界项 / 全部载体 | 0.05 – 0.25 | 0 → 假装全知；>0.3 → 标准残缺 |

## 6 陷阱库（HJ 84 实证）

| # | 陷阱 | 表现 | 正确做法 |
|---|---|---|---|
| T1 | 资料性附录含可判信息 | 附录B 峰序两套体系不同 → 可判峰识别错 | 不按"资料性"跳过；抽 M + 规则 |
| T2 | 规范性条款含不可判内容 | "色谱柱应亲水、高容量" 报告不写 | 不进 R；标 `manual_only` |
| T3 | 表注/图注藏关键约束 | "注：ND 表示未检出" | 表注逐条扫，抽成规则或词表 |
| T4 | 引用即转移 | "按 HJ 494 采样" 本条无内容 | 抽 B(REF_PENDING)，不猜内容 |
| T5 | 同一表格混装判据与档案 | 表4 曲线浓度点（判据）/表A.1 精密度（档案） | 逐表判，不整块判 |

## 7 与下游契约

- 运行层只导入 R/P/M/G/B；A 与 SKIP 进档案索引，按需检索。
- 每个 R 必须带 `primitives[]`（≥1 个 P1–P8 编号），否则 validator 拒绝。
- 每个 A 必须带 `retrieval_key`；每个 B 必须带 `affected_rules[]`。

## 8 合并抽取规则（规模化必需）

**允许合并，但必须显式登记**，否则会重演 HJ 84 第一版的"ID 冲突"：
- 合并条件：同章、同载体类型、谓词结构相同（如 8 条标准贮备液都是「称样量×定容→1000 mg/L」）。
- 必填 `source_clauses[]`，且每条源条款可独立回指。
- 合并后仍须能回答三问；不能因为合并丢掉某一条的适用条件差异（如 SO₃²⁻ 需加甲醛）。

## 9 隐含模态（v0 的教训）

条款不带"应/须"≠ 不是要求。例：「结果保留三位有效数字」——没有模态词，但必须判。
**判据不是看有没有"应"，是看能不能归约到 P1–P8。** 模态只决定 obligation 字段（MUST/SHOULD/MAY），不决定抽不抽。

## 10 回测与收敛（HJ 84-2016，86 条款）

| 版本 | 一致率 | 修正点 |
|---|---|---|
| v0（纯关键词） | 60.5% | 以模态词为门槛 → 漏掉全部隐含模态条款 |
| v1（+章节结构先验） | 66.3% | 引入"试剂/仪器/样品/步骤/计算/质控"骨架 |
| v1（+合并口径） | 97.7% | 回测指标不再把"合并抽取"误判为漏抽 |
| 定稿（+双载体/护栏挂附录） | **100%** | 第 2 章同时产生边界与规则；护栏挂在附录不逐表重复 |

四条修正全部是**口径修正**，没有一条是"补抽内容"——说明闸本身是稳的，不稳的是度量方式。

规模化度量实测：ρ=1.28　e=98.9%　a=0.05　b=0.07，四项全部在健康区间。

## 11 1000 个标准的跑法

```
批次 0：闸 → 每标准产出（载体清单 + ρ/e/a/b 指标），不抽内容
批次 1：按载体类型分批抽取（R 优先，A 最后）
批次 2：validator 硬门（每 R 有 primitives+anchor；每 P 有 provenance；每 B 有 affected_rules）
批次 3：指标看板筛异常（ρ<0.3 / e<0.9 / a>0.5 / b=0）→ 异常标准回炉
批次 4：10% 抽样人工核 + 冲突项入人工队列（禁止静默吸收）
```

**四个指标能在不看内容的情况下发现 80% 的抽偏**，这是 1000 标准可运维的前提。

## 12 回测结果（4 个真实标准）

| 标准 | 文本层 | 条款 | 规则 | 闸判对 | 漏判 |
|---|---|---|---|---|---|
| HJ 84-2016 阴离子 | 无 | 86 | 96 | 99% | 0 |
| HJ 535-2009 氨氮 | 有 | 39 | 29 | 97% | 0 |
| HJ 671-2013 总磷 | 有 | 47 | 34 | 100% | 0 |
| HJ 636-2012 总氮 | 无 | 35 | 28 | 100% | 0 |

实测：判据密度 ρ=0.90，闸的漏判在四份标准上均为 0。

## 13 章节角色必须来自目次（v2 教训）

HJ 84 第 2 章=规范性引用，HJ 535 第 2 章=方法原理。**按章节号判角色必错**；必须解析目次页得到「章号→章标题」，再按标题分词定角色。子条款继承父章角色，自身标题命中则覆盖。

## 14 参照数据的三条护栏

1. 性能数据（精密度/准确度/重复性限/再现性限）→ 只进 A 档案。
2. 必须同时产出 G 护栏规则：「不得作为日常合格判据」。
3. 若正文与附录数值冲突 → GAP-CONFLICT，不裁决。

已实证两次踩坑：HJ 84 附录 A 的 r/R、HJ 535 第 9 章的回收率区间，都曾被误做成判定阈值。

# 检测报告审核专家（report-audit-expert）

按已匹配标准的 C1 方法适用性、C6 数据与计算规则，审核检测报告正文与结果页，输出逐条判定、报告文字位置和条款回指。

## 定位

- 审：报告方法声明、结果表、检出限、公式复算、结果表示、报告字段。
- 不审：原始记录、试剂、仪器运行、环境、质控频次（归过程文档审核专家）。
- 不抽数、不改证据包、不解释标准。

## 关键口径

- method_match=mismatch 的标准不套规则，全部 CONFLICT_PENDING；
- 缺证不默认通过，按 on_missing；
- 每条结果带 rule_id、verdict、target span、clause anchor。

## 样例

202203001：总磷声明 GB 11893-89，与库内 HJ 671-2013 不一致 → 39 条总磷规则 CONFLICT_PENDING；总氮/氨氮/阴离子正常审核 55 条规则。

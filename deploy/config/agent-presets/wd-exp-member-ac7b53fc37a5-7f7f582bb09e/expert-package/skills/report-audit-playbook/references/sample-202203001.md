# 样例审核：202203001 检测报告

## 1 报告事实

- 报告编号 202203001-1，5 页；机构中国环境科学研究院环境检测与实验中心；委托方污控中心。
- 样品：废水，15 个；采样/接收 2022-03-15～17；检测 2022-03-16～22；报告日期 2022-03-25。
- 方法：总氮 HJ 636-2012；总磷 GB 11893-89；氨氮 HJ 535-2009；阴离子 HJ 84-2016。
- 仪器：UV UH5300（N-187）；IC ICS5000+（N-210）。
- 结果表 5 列（总磷、总氮、氨氮、NO3−、PO4 3−），检出限 0.01 / 0.05 / 0.025 / 0.016 / 0.051 mg/L。

## 2 预期发现

1. **方法 mismatch**：总磷声明 GB 11893-89，库内标准 HJ 671-2013；HJ 671 的 39 条规则全部 CONFLICT_PENDING，不得用 HJ 671 判总磷。
2. **方法匹配**：总氮 HJ 636、氨氮 HJ 535、阴离子 HJ 84 可正常审核（55 条规则）。
3. **适用性**：总氮 0.20–7.00 mg/L、氨氮 0.10–2.0 mg/L、总磷（GB 11893）不套 HJ 671 量程；结果超出各自量程需稀释记录。
4. **结果表示**：总氮 <1.00 两位小数、≥1.00 三位有效；氨氮标准未给结果表示规则（gap），不得套用其他标准。
5. **公式复算**：总氮按 F-1/F-2、氨氮按 F-1 复算；证据不足时 UNVERIFIABLE。
6. **报告字段**：方法依据、仪器编号、检出限、单位、签字/章。

## 3 证据不足

- 检测报告为扫描件 OCR，部分数值字符不确定；复算前须回原文核对。
- UV 校准证书是否在包内待 4 号确认；总磷 GB 11893 未入库，无法审核其方法细则。

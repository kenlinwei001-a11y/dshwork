# 文档类型与抽取字段

## 1 类型清单

| doc_type | 中文 | 主要字段 |
|---|---|---|
| report | 检测报告 | 报告编号、委托方、样品、日期、方法、仪器、结果表、检出限、结论、签字/章 |
| commission | 测试委托书 | 委托方、项目、样品、检测参数、时限、送样方式 |
| contract_review | 合同评审记录 | 能力覆盖、方法、资源、分包、风险、结论 |
| task_order | 检测任务单 | 任务号、样品、项目、方法、人员、计划日期 |
| sample_log | 样品出入库登记表 | 样品编号、数量、状态、交接、保存条件 |
| risk_assessment | 检测风险评估表 | 风险项、等级、控制措施 |
| raw_record | 原始记录表 | 项目、方法、仪器、校准、空白、平行、加标、试剂、环境、计算 |
| environment | 环境记录表 | 温度、湿度、日期、房间、记录人 |
| instrument_log | 仪器运行记录 | 仪器编号、开机/关机、参数、使用人、状态、维护 |
| calibration_cert | 仪器校准证书 | 仪器编号、校准日期、有效期、不确定度、校准机构 |

## 2 报告结果表

- 逐样品、逐项目抽：样品编号、客户编号、项目、结果、单位、检出限、样品状态。
- 表头与单位必须一起抽；合并单元格拆成行列坐标。
- ND / 未检出 / <检出限 原样保留，不转 0。
- 报告声明的方法与仪器编号单独抽 methods / instruments。

## 3 原始记录（raw_record）

| 分组 | 字段 |
|---|---|
| 基本信息 | 项目、方法、样品编号、日期、分析人员、复核人员 |
| 校准 | 浓度点、信号值、回归方程、截距、斜率、相关系数、校准日期 |
| 空白 | 空白数量、空白值、单位、判定 |
| 平行 | 平行样编号、两次结果、相对偏差 |
| 加标 | 加标量、加标后结果、回收率 |
| 质控样 | 批号、浓度、结果、不确定度 |
| 试剂 | 名称、批号、浓度、配制日期、有效期 |
| 仪器 | 编号、型号、参数、状态 |
| 环境 | 温度、湿度 |
| 计算 | 公式、代入值、结果、修约 |

## 4 缺失判定

对照项目涉及的检测方法，检查每个方法应有：
- 原始记录（每个项目一本/一册）
- 校准曲线记录（可含在原始记录内）
- 空白/平行/加标记录（可含在原始记录内）
- 仪器运行记录（涉及仪器）
- 环境记录（温湿度）
- 试剂配制记录（如标准要求）
- 样品流转记录
- 仪器校准证书（在有效期内）

缺哪类就登记 missing；不要用报告正文替代原始记录。

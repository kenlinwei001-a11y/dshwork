## 二、两大主题的串行关系

```
知识处理（主题一）                         推演写作（主题二）
docx/pdf → [3 解析] → [4/5 切块分句] → [6-15 抽取] → [18 编译] → [17/20 校验审计]
   → corpus_run 七道工序 → 30 文件语料包 → draft→validated→published → corpus-library（历史资产库）
                                                                          ↓ 写新项目时
   library_find_analog 找最相似语料包 → schema_diff+resolve_concept → instantiate_project
   → build_work_package → [19 推演写作] → gate_check_draft → 回写图谱（可反向回读）
```

## 三、每个技能的文档结构（skills/*.md）

每份技能文档包含：名称与 ID、一句话定位、在流水线中的角色、输入契约、输出契约、执行规则（确定性/语义、校验与重试）、与其他技能的关系、绑定专家、典型触发语。

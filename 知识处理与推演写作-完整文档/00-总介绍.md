# 知识处理与推演写作 · 总介绍

> 本文档是「知识处理 + 推演写作」双主题体系的完整说明包的入口。本包把体系拆成
> 项目 / 专家 / 插件 / Skill / MCP 五类文档，每类单独成文、每个 Skill 单独成文。

## 一、两大主题

### 主题一：知识处理（Knowledge Processing）

把历史稿件（PDF / DOCX / XLSX / PPTX / 扫描件，以及历史报告语料库）处理为**可审计的结构化知识图谱**，并进一步发布为**可复用资产**（语料包）。核心方法：**工具 + LLM 分层**——确定性步骤（解析、分句、切块、建图、溯源、数字/时间冲突、schema 校验）由代码执行、零 LLM、可复现可单测；语义步骤（实体/事实/关系/Claim/证据/推理抽取、证据判断）才调 LLM，且必须结构化输出 + validator 校验 + 失败重试。

- 七道工序：归一化 → 骨架抽取 → 切块 → 本体抽取 → 推演回放 → 质量登记 → 脱敏索引
- 产出：30 文件契约语料包（含脱敏骨架 skeletons.jsonl）
- 资产治理：候选→正式状态机（draft→validated→published）、16 域依赖图、三质量关口（QG1/QG2/QG3）、知识≠能力双路径

### 主题二：推演写作（Deductive Writing）

在已编译语义图谱之上**沿推理链前向推演**，把每条论断写成**绑定证据与溯源链**的报告正文（DOCX）。核心纪律：**借形不借值**（继承历史骨架/推导逻辑/句式，绝不继承历史数值）、**缺值守卫**（undefined 不按 0 计算）、**引用即绑定**（数值写 node 引用不写字面量）、**冲突待审**（不裁决不改数字）、**正文可反向回读**（改稿回写图谱）。

- 写新项目时：先经 `library_*` 发现最相似历史语料包 → `schema_diff` + `resolve_concept` 语义对齐 → `instantiate_project` 建新项目图库 → `build_work_package` 组包 → 按工作包写作 → `gate_check_draft` 闸门 → 回写闭环。

## 二、五形态边界（一切能力的归属判据）

| 形态 | 职责 | 现有实现 |
|---|---|---|
| 确定性代码 | 结构比对、字段校验、DAG 排序、版本比较、事务发布 | schema_diff.py / contracts.py / validate.py |
| Skill | 有明确输入输出契约的语义任务（抽取/判断） | 21+ 技能（见技能总览） |
| MCP | 授权后的资产/查询/函数/系统操作暴露为标准接口 | kp-* 5 组 65 工具 |
| Agent | 提计划、选路径、处理需推理的决策 | 知识处理专家 / 推演写作专家 |
| Workflow/规则引擎 | 调度、依赖、重试、审批、闸门 | DAGRuntime / orchestrator / AssetPublisher |

**红线**：MCP 不做流程规划；Schema Diff/DAG 排序/JSON Schema 校验必须确定性代码；Claim 抽取用 Skill 调 LLM；历史资产检索走 MCP 受控接口（不直开数据库）；复用决策用规则引擎 + 确定性代码。

## 三、系统分层（六层）

```
应用层    项目工作台 · 历史资产库 · 装配差异预览 · 审批与发布
编排层    Planner Agent · Workflow Orchestrator · DAG Runtime · Approval Workflow
装配服务层 Schema Diff · Asset Resolver · Asset Assembler · Dependency Analyzer · Validation Engine
能力执行层 Skills · 函数执行器 · 规则引擎 · LLM Gateway · MCP Client
受控工具接口层 kp-processing(30) / kp-assembly(16) / kp-library(7) / kp-semantic(6) / kp-reserved(6)
数据存储层 PostgreSQL · 图数据库 · 向量检索 · 对象存储（当前：文件系统，预留 DB/图/向量升级位）
```

上层只能调用下层；禁止跨层直连。

## 四、八大边界红线（违反即缺陷）

1. 不裁决冲突：冲突一律「待审」，不补数字、不改口径。
2. 借形不借值：可继承骨架/推导逻辑/句式，一律不继承历史数值。
3. 缺值守卫：undefined 节点不按 0 计算，写「待……后测算」并挂 gap。
4. 引用即绑定：每处数值写 node 引用，不写字面量。
5. 未验证不标已证：status=unverified 不得写成已验证/事实。
6. 不开放原文：chunks.jsonl / normalized.md / original 永不返回字面数值。
7. 审批才发布：无审批人拒绝发布；base_version 过期拒绝并发覆盖。
8. 默认拒绝：访问控制 fail-closed，未授权即拒绝。

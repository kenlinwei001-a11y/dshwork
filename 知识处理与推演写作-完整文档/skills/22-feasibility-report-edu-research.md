# Skill · feasibility-report-edu-research

## 名称与定位

- **名称**：`feasibility-report-edu-research`
- **一句话**：编制、审校、修订【高校科研用房】类项目的可行性研究报告，一律以国家发改委发改投资规〔2023〕304 号《政府投资项目可行性研究报告编写通用大纲》为基准。

## 角色

「推演写作」主题的**领域应用**：把本体图谱驱动写作落地到高校科研用房可研报告，是 graph-deductive-writing-skill 的领域实例（知识处理专家绑定）。

## 交付物

| | 是什么 | 交不交付 |
|---|---|---|
| out/report.docx | 最终成品（客户拿到的可研报告） | ✅ 交付物 |
| out/check.txt | 一致性检查报告 | ✅ 随文交付 |
| audit/ | 派生轨迹与防篡改指纹 | ✅ 备查 |
| project.yaml | 实例图（中间产物） | ❌ 不单独交付 |
| content.yaml | 正文模板（中间产物） | ❌ 不单独交付 |

**客户要的是能打开、能改、能报审的 Word 文档**，只交 YAML 等于交半成品。

## 解决的问题

一份可研报告 130 页、十几章、几十张表，支撑它的事实节点通常只有 60 个左右，其余全是这些事实的自然语言表述与派生关系。真实样本里「总建筑面积」一个数字横跨 7 个专业领域出现 11 次——人工改一处漏十处。把报告当成**图的一次渲染**，而不是一篇文章，这类事故在物理上就不可能发生。

## 适用与不适用

- 适用：高校研究中心、研究院、重点实验室、科研实验楼、交叉研究平台、中试基地及配套用房。
- 不适用：学生宿舍与食堂（feasibility-report-edu-student-life）、教学楼图书馆、产业园区厂房、施工图设计、招标文件编制。
- 触发词：科研楼可研 / 实验楼立项 / 研究中心可行性研究 / 科研用房建设规模论证 / 人均科研用房面积指标 / 建标191-2018 / 2023 新大纲改口径。

## 关键机制

- 所有事实只存一份、跨章自动传播；每条论断绑定证据；法定章节覆盖自动校验；客户改稿可反向回读。
- 生成命令：`python -m …`（出稿，需 python-docx）。

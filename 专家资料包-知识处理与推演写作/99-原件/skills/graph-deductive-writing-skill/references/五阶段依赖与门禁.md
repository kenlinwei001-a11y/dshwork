## 五个阶段的依赖与门禁

```
G0 载入校验
    ↓
G1 建计划 → G2 前向推演 → G3 论断分级
                              ↓
                        G4 溯源写作
                              ↓
                        G5 反向回读
```

| 门禁 | 不通过的后果 |
|---|---|
| G0 图谱契约 | 分类错，全文句式错 |
| G1 计划 | 空节大量出现 |
| G2 派生 | 数值无来源，读者以为算过 |
| G3 分级 | 无依据的论断写成结论 |
| G4 写作 | 数值无锚点，不可回读 |
| G5 回读 | 溯源链断，无法审计 |

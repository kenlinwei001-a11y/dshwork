# 完整示例：PX-2026-001 锂电制造基地扩产与订单交付风险分析

本示例以一份已编译的语义图谱（`PX-2026-001_semantic_graph.json`）为输入，展示从图谱到
推演再到报告的完整链路。图谱规模：12 实体、10 关系、18 事实、6 推理、17 论断、8 证据、
4 冲突、17 校验。

## 输入图谱摘要

- **实体**：华东锂电制造集团(ORG) → 武汉基地(BASE) → A车间(WS) → A01/A02 线；客户
  C1/C2/C3；材料 M01；供应商 S1；承运商(CAR)。
- **关键事实**：A01 有效月产能 20 GWh、A02 16 GWh、合计 36 GWh（F01–F03）；8 月订单
  33 GWh（F04）；9–11 月月均需求 39 GWh（F08）；M01 库存 4800 吨 → 可支持 34 GWh（F12/F13）。
- **推理链**：R1(20+16=36) → R2(20−1=19, A01 维护后) → R3(19+16=35) → R4(35−33=2, 8月余量)
  ；R5(39−36=3, 缺口)；R6(39−34=5, 材料缺口，口径存疑)。
- **冲突**：CF1(口径：流量−存量)、CF2(数字)、CF3(时间一致性)、CF4(覆盖完整性：物流未计入)。

## 推演过程（前向传播）

1. 拓扑序：facts → R1..R6 → CL1..CL17。
2. 沿 R1→R3 得「维护后基地有效月产能 35 GWh」（CL1）。
3. 沿 R4 得「8 月理论余量 2 GWh」（CL2），但标记 PARTIAL_SUPPORT（CF4：未计物流）。
4. 沿 R5 得「9–11 月缺口 3 GWh/月」（CL3，SUPPORT）。
5. R6 命中 CF1（口径错误），CL4 被校验为 CONTRADICT → 转待审，不作为既定结论。
6. 情景分支：CL6(情景A 缺口3)、CL7(情景B 缺口1)、CL8(情景C 产能为约束) 并列呈现。
7. 派生结论登记：从 F12/F13/F14 换算（4800 吨→34 GWh，1200 吨→约 8.5 GWh）得「S1
   到货后材料可支持约 42.5 GWh」，标注为推演结论并绑定 E4/E5。

## 报告骨架（按 assets/report-outline.md）

1. 执行摘要：结论先行——「维护后产能 35 GWh，9–11 月存在约 3 GWh/月缺口；材料库存另有
   口径待审项」。
2. 事实与现状：事实表（F01–F18 单源列出）。
3. 推演过程：R1→R6 逐步推导，每步绑定公式与证据。
4. 情景分析：CL6/CL7/CL8 并列，各自给假设与结果。
5. 风险清单：CL9–CL13（产能缺口 / 材料不足 / 供应商承诺未入库 / 维护波动 / 物流波动）。
6. 建议与行动项：CL14–CL17。
7. 待审事项：CF1–CF4 显式列出，不裁决。
8. 证据附录：E1–E8 清单 + 全文溯源表。

## 关键教学点

- **CF1 是口径错误的典范**：存量(34 GWh)与流量(39 GWh/月)相减。推演必须先统一口径，
  写作时该结论必须转「待审」而非写成既定缺口。
- **CF4 是覆盖完整性**：产能测算未纳入物流运力(12 车/日)与运输周期(2–4 天)，故 CL2 只能
  PARTIAL_SUPPORT。
- **「承诺·未入库」证据**：E5 只能支撑「S1 追加不能视为已确认库存」这一判断(CL5)，
  不能支撑结论性产能数字。

## 四道闸门

| 闸门 | 时机 | 拦住什么 |
|---|---|---|
| **G1 骨架确认** | 分诊完成后，一切内容工作之前 | 全部后续动作 |
| **G2 关键事实确认** | 高阻塞度节点取值确定时 | 依赖它的全部章节的起草 |
| **G3 逐章确认** | 每章起草完成时 | 该章 provides 节点的冻结 |
| **G4 出稿** | 全部章节完成 | C1–C7 未全绿或未留痕裁决 |

G1 之所以是硬闸门：章节 id 是全图的引用锚点，冻结后再改等于全图返工。

### 两套门禁的关系（别混）

| 套 | 管什么 | 何时触发 | 编号 |
|---|---|---|---|
| **G1–G4 流程闸门** | **能不能进入下一步** | 骨架完成 / 关键事实确定 / 每章完成 / 全章完成 | G |
| **F1–F6 工序门禁** | **这一步的产出合不合格** | 每道工序产出时 | F |

```
G1 骨架确认  ──→ 工序1 素材摄入 → F1
                 工序2 来源路由 → F2
G2 关键事实  ──→ 工序3 规模论证 → F3
                 工序4 投资估算 → F4
G3 逐章确认  ──→ 工序5 论断写作 → F5
                 工序6 冲突呈现 → F6
G4 出稿      ──→ （汇总 F1–F6 全绿 + C1–C7 全绿）
```

**G4 出稿的条件就是「F1–F6 全绿」**，所以不再单设 F7。

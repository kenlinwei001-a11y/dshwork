## 2. 五者关系（一句话版）

插件是安装与供货单元，专家 / Skill / 项目 / MCP 连接是插件管理的业务对象；项目把专家＋Skill＋连接器组合成一次任务的能力快照，交给 Harness 原生 Agent 执行。

~~~text
DSH Profile（组合层：bundles + cordis.patch.yml）
  └─ 插件 plugin（Cordis 包，官方 Loader 加载）
       ├─ skills 插件      → 管理 N 个 Skill（怎么做）
       ├─ experts 插件     → 管理 N 个专家/专家团（谁来做）
       ├─ connectors 插件  → 管理 N 个 MCP 连接（能连什么外部系统）
       └─ projects 插件    → 管理 N 个项目（把上面三类 + 资料 + 任务组织起来）
                                   ↓ 召唤 / 新建任务：能力快照 + 配置修订
                          官方 Agent preset + mcp__<server>__* 工具命名空间
                                   ↓
                          DSH 原生会话（真实 Agent Loop 执行）
~~~

## 4. 怎么用

1. 想快速了解全貌：读本文件与 01-关系总览/01-关系总览.md。
2. 想复用某个专家的专业方法：读 03-专家/ 下对应文档，其中的 Agent MD 即发布冻结正文。
3. 想复用某个 Skill：读 04-技能/ 下对应文档；要直接可用文件，取 99-原件/skills/<name>/。
4. 想把整条链路跑起来：先读 06-MCP/00-MCP总览.md 确认 5 个 kp-* 连接健康，再读 02-项目/ 的能力快照。

## 5. 诚实边界

- 本包描述的是本机当前状态（个人主体 local-user），不是产品承诺；修订号与健康状态会随后续操作变化。
- 专家定义中没有 MCP 字段：MCP 能力来自连接器，由项目或会话选择，不写在专家里。
- 「已保存草稿」「已发布」「已试用」是三件事；本包只陈述采集时刻的状态，不宣称专业成果质量。
- 未采集到的信息一律标注为「未知」，不做补写。

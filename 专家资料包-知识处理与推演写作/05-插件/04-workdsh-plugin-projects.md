# 插件：workdsh-plugin-projects（项目插件）

> 本文件由 WorkDSH 会话依据本机真实数据生成，采集时间（UTC）：2026-10-13T07:33:15Z。

## 1. 是什么

项目工作台：把指令、技能、专家、连接器、资料库资产、计划和原生 DSH 任务组织在同一项目中，但不复制各领域的权威数据。

## 2. 关键机制

- 能力类型固定为 skill / expert / connector，只保存 kind + id + label + revision。
- 配置保存生成不可变修订；任务创建时固定引用当时修订（本机示例：修订 #7 绑定知识处理专家 + knowledge-processing-toolchain + kp-mcp）。
- 运行时经 system-prompt/assemble 注入项目名、配置修订号、项目指令与已选引用，并声明引用是参考数据而非授权。
- 新任务由 Host 解析项目专用目录并通过官方 Workspace Controller 以项目名登记，不使用最近会话目录。
- 项目资产只保存资料库 assetId + revisionId，正文仍由资料库管理。

# 重建说明

本资料包由构建器生成，**不要手工修改**（下次构建会覆盖）。要更新内容：改数据源或配置后重建。

## 1. 两种重建模式

纯磁盘重建（无需会话工具，随时可跑）：

~~~bash
node tools/expert-report/build.mjs
~~~

带运行时观测重建（健康状态、工具清单、技能库启用状态更准）：先刷新 `tools/expert-report/sources/runtime.json`，再执行上面的命令。

## 2. 判断是否过期

~~~bash
node tools/expert-report/build.mjs --check
~~~

逐项比对本机数据与构建清单：输出"未变化"说明包是最新的；否则列出新增 / 变更 / 删除的源。退出码 0=最新，1=已过期，2=没有历史清单。

## 3. 验证幂等性

~~~bash
node tools/expert-report/build.mjs --self-check
~~~

连续构建两次到临时目录，比较全部文档与 ZIP 字节是否完全一致。

## 5. 为什么这样设计

- **全量而非裁剪**：技能按运行时可见集合收录，杜绝"库里有、包里没有"。
- **不变量化**：文档直接从存储读取，不做二次人工整理，杜绝"文档与事实分叉"。
- **可复算**：源单元、源文件、产物、副本四级哈希。
- **确定性**：ZIP 条目排序 + 固定时间基准，源不变则字节不变。

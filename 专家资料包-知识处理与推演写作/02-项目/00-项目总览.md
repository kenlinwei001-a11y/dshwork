## 1. 项目在架构中的位置

项目由 workdsh-plugin-projects 管理，职责是项目说明、任务归属、资产引用与项目访问权限。它不复制专家、Skill、连接器、资料库的权威数据，只保存引用（kind + id + label + revision）。

- 能力类型（契约固定）：ProjectCapabilityKind = skill | expert | connector。
- 每次保存配置生成一个不可变修订；新建任务固定引用创建时的修订，运行中的会话不被后续修改替换。
- 项目任务经 Host 解析项目专用目录（DSH_HOME/workdsh-projects/<主体>/<项目名>/），并通过官方 Workspace Controller 以项目名登记，不使用「最近会话」目录。
